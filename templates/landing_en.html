Setup Guide

1

Turn off Smart App Control

Windows Security → App & browser control → Smart App Control → Off
Required to run unsigned .exe files. Only needs to be done once.

2

Create an account

Click "Get started free" and register with a username and password.

3

Download and launch Toxov.exe

Download via the button above and run it. If Windows SmartScreen appears, click "More info" → "Run anyway". Accept the UAC prompt to grant admin privileges.

4

Enter your connection code

On first launch, a dialog will ask for a code. Open your dashboard, go to "PC Link", and enter the 6-digit code shown there.

5

Configure your block list

In the dashboard, set your block schedule, sites, and apps. Hit "Save settings" and you're done. Blocking starts automatically on every PC startup.

FAQ

Does it actually block sites?

Yes. Toxov uses Windows network and process controls to block sites — not just a browser extension. It's designed to be harder to bypass than typical blockers.

Is it safe?

Yes. Toxov is a productivity tool — it collects minimal personal data. Payments are handled securely by Stripe.

My antivirus flagged it

This is a false positive. Toxov uses network control and background processes, which some antivirus software flags. Temporarily disable your antivirus before downloading, or add an exclusion. Code signing is in progress.

Is Mac or mobile supported?

Currently Windows only. Mac, iOS, and Android versions are planned.

What happens after the free trial?

Your plan activates automatically. Cancel before the trial ends and you won't be charged.

Can I cancel?

Yes, anytime from the settings page in the app.

How do I unblock sites?

You can emergency-unlock from the tray icon. There's a short wait time built in — by design, to stop impulsive unlocking.

Do you offer refunds?

Refunds are not available except in cases of duplicate charges or technical issues on our end.
