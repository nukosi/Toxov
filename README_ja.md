# Toxov

> 🌐 English README: [README.md](README.md)

**Toxov** は、指定した時間帯にWebサイト・アプリを自動でブロックするWindowsアプリです。抜け道がありません。

![Hero](https://toxov.net/static/ogp.png)

---

## なぜToxovか？

ブラウザ拡張機能やアプリタイマーには抜け道があります。別のブラウザを開いたり、拡張機能を無効にするだけで簡単に回避できます。

Toxovは**hostsファイルの書き換え**と**Windowsファイアウォールのルール追加**で直接ブロックするため、簡単には回避できません。Webダッシュボードでスケジュールを設定すれば、PC起動時に自動でブロックが動作します。

## 機能

- **時間帯指定ブロック** — 開始・終了時刻をブラウザから設定、自動で動作
- **サイト＋アプリ両対応** — hostsファイルでWebサイト、ファイアウォールでアプリをブロック
- **抜け道なし** — 全ブラウザに対応、無効化できる拡張機能なし
- **ストリーク** — 緊急解除なしの連続日数を記録
- **ポイント・シーズンランキング** — モチベーション維持のランキング機能
- **緊急解除** — 本当に必要な時だけ使用可能（ポイントペナルティあり）
- **ストリークシールド** — 月1回ストリークを守れる（プレミアム限定）
- **日本語・英語対応**

1. [toxov.net](https://toxov.net) でアカウントを作成
2. ダッシュボードからブロック時間帯・サイト・アプリを設定して保存
3. `Toxov.exe` をダウンロードして起動
4. 「PC連携」画面に表示される **6文字のコード** を入力
5. 完了 — PC起動時に自動でブロックが動作します

## よくある質問

**Q: 他のブラウザにも効きますか？**
A: はい。hostsファイルを書き換えるため、PC上の全ブラウザに適用されます。

**Q: Toxov.exeを別のフォルダに移動しても大丈夫ですか？**
A: 大丈夫です。起動するたびにタスクスケジューラのパスが自動更新されます。

**Q: SmartScreenの警告が出ます。安全ですか？**
A: 安全です。コードサイニング証明書未取得のためSmartScreenが反応します。「詳細情報」→「実行」をクリックしてください。VirusTotalでも確認できます（下記参照）。

**Q: Mac・スマホには対応していますか？**
A: 現在はWindows専用です。ロードマップをご覧ください。

**Q: アンインストールするには？**
A: `Toxov.exe` を削除し、Windowsタスクスケジューラから「Toxov」タスクを削除してください。toxov.netのアカウントとデータは別途管理されています。
